BOM-Report Kompas 3D

Описание 
BOM-Report для Kompas 3D можно использовать для простого управления и экспорта ведомости материалов (BOM) Kompas 3D в различные форматы (CSV, DOCX, PDF, HTML, XML, XLSX, XLS). Дополнительные свойства, такие как эскизы деталей / сборок, также можно экспортировать в различные форматы (CSV, DOCX, PDF, HTML, XML, XLSX, XLS). Также могут быть включены другие полезные свойства, такие как добавление произвольного параметра/переменной из модели/сборки.
Интерфейс интуитивно понятен и позволяет легко управлять данными и проверять их перед экспортом в различные форматы.

Замечания:
- Значок BOM-Report будет доступен на вашем рабочем столе.

- Приложение Kompas 3D также должно быть запущено, чтобы приложение работало.

- Версия Kompas 3D должна соответствовать рекомендованной версии, для корректной работы приложения и анализа состава сборки
